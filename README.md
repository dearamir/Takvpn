## English

**TakVPN** is an Android VPN client that helps users import, organize, manage, and test supported connection configurations, then connect through an available configuration.

### Download

Get the latest Android APK from the official GitHub Releases page:

**[Download the latest TakVPN APK](https://github.com/dearamir/Takvpn/releases/latest)**

The Releases page lists the available APK variants for each published version. Choose the variant compatible with your device; if you are unsure, check the release notes and device architecture before installing.

### Features

- Import and manage supported VPN configurations
- Organize and sort saved configurations
- Test connection availability and latency where supported
- Connect and disconnect from supported configurations
- Check for app updates and review release notes

### Installation

1. Open the [latest release](https://github.com/dearamir/Takvpn/releases/latest).
2. Download the APK variant compatible with your Android device.
3. Open the downloaded APK. If Android asks, allow installation from that source.
4. Complete installation and launch TakVPN.

## فارسی

**تاک‌وی‌پی‌ان (TakVPN)** یک کلاینت VPN برای سیستم‌عامل اندروید است که امکان واردکردن، مدیریت، مرتب‌سازی و آزمایش کانفیگ‌های پشتیبانی‌شده و اتصال از طریق آن‌ها را فراهم می‌کند.

### دانلود

**[دانلود آخرین نسخه تاک‌وی‌پی‌ان (APK)](https://github.com/dearamir/Takvpn/releases/latest)**

در صفحه انتشار، فایل‌های APK موجود برای هر نسخه نمایش داده می‌شوند. فایل سازگار با معماری گوشی خود را انتخاب کنید؛ اگر مطمئن نیستید، توضیحات همان انتشار و معماری دستگاه را بررسی کنید.

### امکانات

- واردکردن و مدیریت کانفیگ‌های VPN پشتیبانی‌شده
- مرتب‌سازی و سازمان‌دهی کانفیگ‌های ذخیره‌شده
- آزمایش دسترس‌پذیری و تأخیر اتصال، در صورت پشتیبانی
- اتصال و قطع اتصال از طریق کانفیگ‌های پشتیبانی‌شده
- بررسی به‌روزرسانی برنامه و مشاهده تغییرات نسخه‌ها
